# Godot components

Use Godot 4.3+ and copy individual scripts into `res://addons/gdt/` inside the target project. The `demo/` project includes copies at `addons/gdt/` for straightforward import. Keep module copies in sync when updating the library.

To run: open `demo/project.godot` in Godot and press F6/F5. You can add a different background/theme and test on mobile afterwards. Godot is not installed in the generation environment, so engine-level validation has not yet been performed.
