# Shared Game Development Knowledge Vault

Start at [INDEX.md](INDEX.md). This folder is intentionally plain Markdown and can be opened as an Obsidian vault, browsed on GitHub, or read selectively by a coding agent. Obsidian, MCP and a vector database are **not required**.

**Scope:** cross-project engineering practices, research pointers and reusable workflows. **Not:** project source-of-truth for specific mechanics or game state. Each game owns its own architecture, decisions, issues and session handoffs in its repository.

## How to use

1. Read the [index](INDEX.md) and select only the relevant page.
2. Validate advice against the current target repo and engine version before editing code.
3. Prefer links to existing toolkit modules over duplicating their documentation.
4. After verified changes, update only the affected knowledge page; keep it short.
5. Never store credentials, private notes, personal data or generated runtime caches in this public repository.

The project starter templates are maintained separately at `templates/project/` in the repository root; they are not part of this central vault. See the repository README for onboarding.
